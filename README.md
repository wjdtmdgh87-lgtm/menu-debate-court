# 메뉴재판 · LLM 멀티 에이전트 메뉴 선정

여러 사람이 먹고 싶은 메뉴를 입력하면, AI 에이전트들이 **법정 공방**(변호인·검사·판사)으로 다투고 판사 AI가 최종 메뉴를 판결하는 서비스입니다. 결과는 재판 대본 형식으로 출력됩니다.

> 이 레포는 프로젝트 소개용입니다. 코드는 팀 비공개 레포에서 개발 중입니다.

| | |
| :--- | :--- |
| **기간** | 2026.07.21 ~ 진행 중 |
| **팀** | 4인 · 백본 / 에이전트·프롬프트 / LLM·평가 / 인터페이스로 역할 분담 |
| **내 역할** | 에이전트·프롬프트 트랙 |
| **주요 스택** | LangGraph · LiteLLM · Pydantic · Streamlit |

## 동작 흐름

```text
참가자별 메뉴 입력 → 변호인 에이전트가 메뉴별 변론 → 검사 에이전트 반박 → 라운드 반복 → 판사 에이전트 판결 → 재판 대본 출력
```

## 내가 한 일

- 변호인·검사·판사 역할별 프롬프트와 페르소나 설계
- 에이전트 출력을 JSON 구조화 출력으로 받고, 생성 오류를 처리하는 공통 로직 작성
